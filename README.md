# Student Data-Processing App

## Project Description
The Student Data-Processing App is a simple Python application that loads raw student data, cleans missing or invalid values, and processes numerical data using NumPy.

## Objectives
- Load raw data from a list or CSV file.
- Clean missing and invalid data using Python functions.
- Process numerical data using NumPy.
- Calculate statistical measures such as mean and standard deviation.
- Display the processed results in a Jupyter Notebook.

## Technologies Used
- Python
- NumPy
- Pandas
- Jupyter Notebook
- Git and GitHub

## Project Files
- `data_processing.py` – Contains data-cleaning and processing functions.
- `main.py` – Runs the data-processing application.
- `requirements.txt` – Lists the required Python libraries.
- `student_data_processing.ipynb` – Demonstrates the application in Jupyter Notebook.

## Installation and Usage

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:
   ```bash
   cd student-data-processing-app
   ```

3. Create a virtual environment:
   ```bash
   python -m venv venv
   ```

4. Activate it on Windows:
   ```bash
   venv\Scripts\activate
   ```

5. Install the required libraries:
   ```bash
   pip install -r requirements.txt
   ```

6. Run the application:
   ```bash
   python main.py
   ```

## Expected Output
The application will display cleaned student data, dataset shape, mean, standard deviation, and other numerical analysis results.
